Section 1: Common Errors and Solutions
================================================================================

Error 1: SyntaxError: Invalid Syntax
Problem: Forgetting colon (:) after if, for, while, def, etc.

❌ Wrong:
if age > 18
    print("Adult")

✅ Correct:
if age > 18:
    print("Adult")

Error 2: IndentationError
Problem: Incorrect indentation (Python uses indentation instead of braces)

❌ Wrong:
for i in range(5):
print(i)

✅ Correct:
for i in range(5):
    print(i)

Error 3: NameError: Name is Not Defined
Problem: Using variable before defining it or spelling wrong

❌ Wrong:
print(name)
name = "Ali"

✅ Correct:
name = "Ali"
print(name)

Error 4: TypeError: Unsupported Operand Type
Problem: Using incompatible data types together

❌ Wrong:
result = "Hello" + 5
# Can't add string and integer

✅ Correct:
result = "Hello" + str(5)
# result = "Hello5"

Error 5: IndexError: List Index Out of Range
Problem: Accessing index that doesn't exist in list

❌ Wrong:
fruits = ["apple", "banana"]
print(fruits[5])  # Only indices 0 and 1 exist

✅ Correct:
print(fruits[0])  # "apple"
print(fruits[1])  # "banana"
# Or check length first:
if len(fruits) > 5:
    print(fruits[5])

Error 6: KeyError: Dictionary Key Not Found
Problem: Accessing non-existent key in dictionary

❌ Wrong:
student = {"name": "Ali"}
print(student["age"])  # "age" key doesn't exist

✅ Correct:
print(student.get("age"))  # Returns None if not found
# Or check first:
if "age" in student:
    print(student["age"])

Error 7: AttributeError: Object has No Attribute
Problem: Calling method that doesn't exist on object

❌ Wrong:
text = "Hello"
text.append("!")  # Strings don't have append method

✅ Correct:
text = "Hello"
text = text + "!"  # String concatenation

Error 8: ValueError: Invalid Value for Function
Problem: Passing wrong type of value to function

❌ Wrong:
age = int("twenty")  # Can't convert text "twenty" to integer

✅ Correct:
age = int("20")  # Converts string "20" to 20
# Or check first:
try:
    age = int("twenty")
except ValueError:
    print("Please enter a valid number")

Error 9: FileNotFoundError
Problem: Trying to open file that doesn't exist

❌ Wrong:
file = open("data.txt", "r")  # File doesn't exist

✅ Correct:
try:
    file = open("data.txt", "r")
except FileNotFoundError:
    print("File not found. Creating new file.")

Error 10: ImportError: No Module Named
Problem: Trying to import module that's not installed

❌ Wrong:
import pandas  # pandas not installed

✅ Correct:
# First install: pip install pandas
# Then use:
import pandas as pd

Section 2: Frequently Asked Questions
================================================================================

Q1: What's the difference between == and is?
A: == checks if values are equal, is checks if objects are same in memory.

a = [1, 2, 3]
b = [1, 2, 3]
a == b  # True (same content)
a is b  # False (different objects)

Q2: How do I check if value is in list?
A: Use the 'in' operator.

fruits = ["apple", "banana", "orange"]
if "apple" in fruits:
    print("Apple found!")

Q3: How do I loop with index and value?
A: Use enumerate() function.

fruits = ["apple", "banana", "orange"]
for index, fruit in enumerate(fruits):
    print(f"{index}: {fruit}")
# Output:
# 0: apple
# 1: banana
# 2: orange

Q4: What's the difference between append() and extend()?
A: append() adds one item, extend() adds multiple items.

list1 = [1, 2, 3]
list1.append(4)      # [1, 2, 3, 4]
list1.extend([5, 6]) # [1, 2, 3, 4, 5, 6]

Q5: How do I get unique values from list?
A: Convert to set.

numbers = [1, 2, 2, 3, 3, 3, 4]
unique = list(set(numbers))  # [1, 2, 3, 4]

Q6: What's a generator?
A: A function that yields values one at a time instead of returning all at once.

def count_up_to(n):
    i = 1
    while i <= n:
        yield i
        i += 1

for num in count_up_to(5):
    print(num)  # Prints 1, 2, 3, 4, 5

Q7: How do I handle exceptions?
A: Use try-except blocks.

try:
    result = 10 / 0  # Will cause error
except ZeroDivisionError:
    print("Cannot divide by zero!")
except Exception as e:
    print(f"An error occurred: {e}")

Q8: What's the difference between list and tuple?
A: Lists are mutable (changeable), tuples are immutable (fixed).

my_list = [1, 2, 3]
my_list[0] = 99  # ✓ Works

my_tuple = (1, 2, 3)
my_tuple[0] = 99  # ✗ Error: tuples don't support item assignment

Q9: How do I sort a list?
A: Use sort() method or sorted() function.

numbers = [3, 1, 4, 1, 5, 9]
numbers.sort()        # [1, 1, 3, 4, 5, 9] - modifies original
sorted(numbers)       # Returns new sorted list

Q10: What's the best way to open files?
A: Use 'with' statement (automatically closes file).

with open("data.txt", "r") as file:
    content = file.read()
    # File automatically closed after this block
